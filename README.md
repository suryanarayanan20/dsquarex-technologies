# DSquareX Technologies — Website

Rebuilt with a distinct visual identity instead of the previous dark
navy + neon glow template.

## What changed and why

- **Palette** — deep charcoal (`#0B0D12`) instead of navy blue, with a
  restrained blue (`#1E6FE0`) and burnt orange (`#E8790C`) pulled from
  your logo, not neon cyan/orange.
- **Type** — Space Grotesk for headings, Inter for body copy,
  JetBrains Mono for labels/tags — gives the site a technical,
  intentional feel instead of one generic font doing everything.
- **Signature idea: "The Crossing"** — your logo's D/X mark is two
  paths crossing. That idea runs through the whole site: diagonal
  seams between sections (instead of straight hairlines), a `/`
  divider in place of numbered markers, and two-letter mono tags
  (`WB`, `AI`, `AU`, `DG`) in place of emoji icons.
- Removed the repeated blurred glow-blob pattern from every section
  — kept one restrained instance in the hero so it reads as a choice,
  not a template default.
- All copy is based on the real content from your previous site
  (About text, services, stats, projects, WhatsApp/email contact) —
  only reworded where needed for clarity and consistency.

## Run it locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

The `dist/` folder is what you deploy to Vercel (same as before).
